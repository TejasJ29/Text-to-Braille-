Hardware Drive Chain & Protection

1. ESP32 GPIO (3.3V Logic): SER=0b110010 • SRCLK • RCLK
2. 74HC595 Shift Register: Q0..Q5 = [1, 1, 0, 0, 1, 0]
3. MOSFET Low-Side Stage: CH1, CH2, CH5 Gate ON + Flyback
4. External Solenoid Rail: Dedicated 5V DC Supply
  • • Inductive Kickback Protection: Parallel 1N4001 flyback diodes clamp reverse EMF spikes to protect driver MOSFETs.
  • • Power Isolation: High solenoid coil current is supplied from an external 5V 2A source, never from microcontroller logic pins.

SIMULATION MODE — NOT ELECTRICALLY CONNECTED TO HARDWARE

1. Microcontroller & Shift Register Role

The ESP32 receives the 6-bit Braille cell pattern and shifts bits serially into a 74HC595 shift register using only 3 GPIO pins (SER, SRCLK, RCLK). Neither the ESP32 GPIOs nor the 74HC595 outputs can source solenoid coil current directly; they strictly provide logic-level gate control signals.

2. Power Stage & Inductive Flyback Protection

Each solenoid is switched by a logic-level N-channel MOSFET powered from a separate DC supply rail. Because solenoid coils are inductive loads, turning off current rapidly induces a high-voltage spike ($V = -L \cdot dI/dt$). A reverse-biased flyback diode across each coil clamps this transient to protect the MOSFET.

3. Simulation Honesty & Hardware Boundary

This browser console runs the complete software translation, bit-packing, and channel sequencing state machine via SimulationAdapter. It is not electrically connected to physical solenoids and never fabricates fake sensor readings for voltage, current, coil temperature, or force.
